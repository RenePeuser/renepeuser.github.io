This series follows one thread through my work: **turning knowledge that lives in people's heads into
software that enforces it.** It starts with VB6 user interfaces next to industrial machines and ends —
for now — with codebases that explain their own rules to humans and AI agents.

Most chapters are retrospectives, written in 2026 and based on the original source code from my
archive. Where the code is public, the posts link to it.
